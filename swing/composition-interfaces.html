Composition d'interfaces utilisateurs - Atomic design ​

L'atomic design, proposé par Brad Frost, est une méthode pour composer une interface utilisateur du plus petit élément au plus grand. Plutôt que de construire chaque fenêtre d'un seul bloc, on assemble des éléments simples et réutilisables en éléments de plus en plus complets.

Contenu pour ta culture générale

Le détail de cette page t'est fourni à titre de référence sur les bonnes pratiques de décomposition d'interface utilisateur, mais ne fera pas l'objet d'évaluation dans le cours de PO2. Il n'est pas nécessaire non plus de l'appliquer dans le travail pratique 2.

Elle peut toutefois t'aider à te faire un schéma mental de la composition des objets Swing, qui suit déjà cette structure, sans les niveaux intermédiaires (molécules et organismes) : des atomes (JLabel, JTextField, JButton) placés dans des JPanel dont le layout définit la disposition (le gabarit), le tout affiché dans une fenêtre JFrame (la page).

Objectifs d'apprentissage ​

Après cette section, tu seras capable de...

  • Décrire les cinq niveaux de l'atomic design
  • Associer chaque niveau à des éléments d'une interface graphique Swing
  • Découper une fenêtre Swing en éléments réutilisables

Les cinq niveaux ​

NiveauDescriptionExemple Swing
AtomesÉléments de base indivisiblesJLabel, JTextField, JButton
MoléculesPetits groupes d'atomes qui forment une unitéUne étiquette et son champ de saisie
OrganismesSections complètes de l'interface utilisateurLe formulaire d'un employé, la barre de boutons
Gabarits (templates)Disposition des organismes dans la page, sans données réellesLe BorderLayout de la fenêtre
PagesGabarit rempli avec de vraies donnéesLa fenêtre affichée à l'utilisateur

La hiérarchie Swing suit naturellement cette logique : des composantes regroupées dans des JPanel de plus en plus grands, jusqu'à la fenêtre.

Exemple - fenêtre d'un employé ​

Molécule : un champ avec son étiquette ​

La paire étiquette et champ de saisie revient dans tous les formulaires. On en fait une classe réutilisable, qui ne connaît rien du domaine : le libellé est reçu en paramètre.

java
public class ChampEtiquete extends JPanel {
    private final JTextField champ;

    public ChampEtiquete(String libelle, int largeur) {
        this.setLayout(new FlowLayout(FlowLayout.LEFT));
        this.champ = new JTextField(largeur);
        this.add(new JLabel(libelle));
        this.add(this.champ);
    }

    public String getValeur()            { return this.champ.getText().trim(); }
    public void setValeur(String valeur) { this.champ.setText(valeur); }
}

Organismes : le formulaire et la barre de boutons ​

Les organismes assemblent des molécules et des atomes en sections complètes.

java
public class FormulaireEmploye extends JPanel {
    private final ChampEtiquete champNom     = new ChampEtiquete("Nom :", 20);
    private final ChampEtiquete champPrenom  = new ChampEtiquete("Prénom :", 20);
    private final ChampEtiquete champSalaire = new ChampEtiquete("Salaire :", 10);

    public FormulaireEmploye() {
        this.setLayout(new GridLayout(0, 1));
        this.add(this.champNom);
        this.add(this.champPrenom);
        this.add(this.champSalaire);
    }

    public void remplir(EmployeDto dto) {
        this.champNom.setValeur(dto.nom());
        this.champPrenom.setValeur(dto.prenom());
        this.champSalaire.setValeur(String.valueOf(dto.salaire()));
    }
}

public class BarreBoutons extends JPanel {

    public BarreBoutons(JButton... boutons) {
        this.setLayout(new FlowLayout(FlowLayout.RIGHT));
        for (JButton bouton : boutons) {
            this.add(bouton);
        }
    }
}

Gabarit et page : la fenêtre ​

La fenêtre dispose les organismes (le gabarit), puis reçoit les données réelles (la page).

java
public class FenetreEmploye extends JFrame {
    private final FormulaireEmploye formulaire = new FormulaireEmploye();

    public FenetreEmploye() {
        this.setTitle("Gestion des employés");

        // Gabarit : disposition des organismes
        this.setLayout(new BorderLayout(10, 10));
        this.add(new JLabel("Employé", SwingConstants.CENTER), BorderLayout.NORTH);
        this.add(this.formulaire, BorderLayout.CENTER);
        this.add(new BarreBoutons(new JButton("Enregistrer"), new JButton("Annuler")),
            BorderLayout.SOUTH);
    }

    // Page : le gabarit rempli avec de vraies données
    public void afficher(EmployeDto dto) {
        this.formulaire.remplir(dto);
        this.pack();
        this.setVisible(true);
    }
}

Bonnes pratiques ​

Pratique✅ À faire❌ À éviter
RéutilisationCréer une classe pour chaque molécule ou organisme qui revient à plusieurs endroitsCopier-coller la même paire JLabel et JTextField dans chaque formulaire
GénéricitéRecevoir le libellé, la largeur ou le texte en paramètre dans les atomes et les moléculesCréer une molécule liée au domaine, comme ChampNomEmploye, inutilisable ailleurs
Flux des donnéesFaire entrer les données par le haut : la page reçoit un DTO et le transmet à ses organismesLaisser une molécule ou un organisme aller chercher lui-même ses données
EncapsulationExposer des méthodes simples (getValeur(), remplir(dto)) qui cachent les composantes internesExposer les JTextField internes pour que d'autres classes les manipulent directement
DispositionChoisir un layout par niveau : FlowLayout pour une molécule, GridLayout pour un formulaire, BorderLayout pour une fenêtrePositionner les composantes au pixel près avec setLayout(null)
