Observateur (Observer) ​

Le patron Observateur (Observer) permet à un objet (le sujet) d'informer automatiquement une liste d'autres objets (les observateurs) lorsque son état change, sans connaître leurs détails d'implémentation.

Objectifs d'apprentissage ​

Après cette section, tu seras capable de...

  • Identifier les quatre composantes du patron Observateur
  • Implémenter Sujet, Observateur, SujetConcret et ObservateurConcret
  • Expliquer le découplage que le patron procure
  • Relier ce patron aux principes SOLID

Patron de l'observateur ​

Structure du patron de l'observateur ​

ComposanteRôle
Sujet (interface)Contrat pour s'abonner/se désabonner et notifier
Observateur (interface)Contrat pour recevoir une notification
SujetConcret (classe)Gère l'état et la liste des observateurs
ObservateurConcret (classe)Réagit aux notifications du sujet

UML ​

Exemple d'observateur ​

On veut modéliser une chaîne de vidéos (style YouTube). Lorsque la chaîne publie une nouvelle vidéo, chaque abonné doit recevoir une notification. La chaîne tient aussi un journal de ses publications.

Interfaces ​

java
public interface Sujet {
    void abonner(Observateur observateur);
    void desabonner(Observateur observateur);
}

public interface Observateur {
    void notifier();
}

Sujet concret ​

Permet de modéliser n'importe quelle chaîne de la plateforme. La classe Video est considérée comme existante (titre, durée, etc.) et n'est pas détaillée ici.

java
public class Chaine implements Sujet {
    private final String nom;
    private final List<Video> videos = new ArrayList<>();
    private final List<Observateur> observateurs = new ArrayList<>();

    public Chaine(String nom) {
        this.nom = nom;
    }

    @Override
    public void abonner(Observateur observateur) {
        this.observateurs.add(observateur);
    }

    @Override
    public void desabonner(Observateur observateur) {
        this.observateurs.remove(observateur);
    }

    @Override
    public void notifier() {
        for (Observateur observateur : this.observateurs) {
            observateur.mettreAJour();
        }
    }

    public void publierVideo(Video video) {
        this.videos.add(video);
        this.notifier();
    }

    public Video getDerniereVideo() { return this.videos.getLast(); }
    public String getNom()          { return this.nom; }
}

Observateurs concrets ​

Notification envoyée à un abonné

java
public class Abonne implements Observateur {
    private final String nom;
    private final Chaine chaine;

    public Abonne(String nom, Chaine chaine) {
        this.nom = nom;
        this.chaine = chaine;
    }

    @Override
    public void notifier() {
        // l'implémentation réelle pourrait envoyer un courriel, une notification push, etc.
        System.out.println("[" + this.nom + "] Nouvelle vidéo de "
            + this.chaine.getNom() + " : " + this.chaine.getDerniereVideo().getTitre());
    }
}

Journal des publications de la chaîne

java
public class JournalPublications implements Observateur {
    private final Chaine chaine;

    public JournalPublications(Chaine chaine) {
        this.chaine = chaine;
    }

    @Override
    public void notifier() {
        System.out.println("[Journal] " + this.chaine.getNom()
            + " a publié : " + this.chaine.getDerniereVideo().getTitre());
    }
}

Utilisation ​

java
Chaine chaine = new Chaine("CodeQuébec");

// Abonnement
Abonne              alice   = new Abonne("Alice", chaine);
Abonne              bob     = new Abonne("Bob", chaine);
JournalPublications journal = new JournalPublications(chaine);
chaine.abonner(alice);
chaine.abonner(bob);
chaine.abonner(journal);

// Publication - notifie automatiquement tous les observateurs
chaine.publierVideo(new Video("Introduction au patron Observateur"));
// [Alice] Nouvelle vidéo de CodeQuébec : Introduction au patron Observateur
// [Bob] Nouvelle vidéo de CodeQuébec : Introduction au patron Observateur
// [Journal] CodeQuébec a publié : Introduction au patron Observateur

// Désabonnement
chaine.desabonner(bob);
chaine.publierVideo(new Video("Le patron Stratégie en 10 minutes"));
// [Alice] Nouvelle vidéo de CodeQuébec : Le patron Stratégie en 10 minutes
// [Journal] CodeQuébec a publié : Le patron Stratégie en 10 minutes
// (Bob ne reçoit plus rien)

Structure UML ​

Caractéristiques clés ​

  • Le sujet ne connaît pas les détails d'implémentation des observateurs - seulement qu'ils implémentent Observateur
  • Il peut y avoir zéro ou plusieurs observateurs à tout moment
  • Les observateurs peuvent s'abonner et se désabonner dynamiquement
  • La liste des observateurs est une composition A_DES dans le sujet

Tester le patron Observateur ​

java
class ChaineTest {

    @Test
    void etantDonneAbonneLorsqueChainePublieVideoAlorsAbonneNotifie() {
        // Étant donné
        Chaine chaine = new Chaine("CodeQuébec");
        int[] compteurNotifications = {0};
        Observateur espion = () -> compteurNotifications[0]++;
        chaine.abonner(espion);

        // Lorsque
        chaine.publierVideo(new Video("Introduction au patron Observateur"));

        // Alors
        assertEquals(1, compteurNotifications[0]);
    }

    @Test
    void etantDonneAbonneDesabonneLorsqueChainePublieVideoAlorsAbonneNonNotifie() {
        Chaine chaine = new Chaine("CodeQuébec");
        int[] compteur = {0};
        Observateur espion = () -> compteur[0]++;
        chaine.abonner(espion);
        chaine.desabonner(espion);

        chaine.publierVideo(new Video("Introduction au patron Observateur"));

        assertEquals(0, compteur[0]);
    }
}

Observateur et pub/sub : une nuance

Les deux termes sont souvent employés comme synonymes, mais au sens strict, le pub/sub ajoute un intermédiaire (un courtier ou un bus de messages) entre l'émetteur et les abonnés. Avec le patron Observateur, le sujet connaît directement sa liste d'observateurs ; avec le pub/sub, l'émetteur et les abonnés ne se connaissent pas du tout.

Vérifie ta compréhension ​

Un entrepôt fait le suivi de la quantité de ses produits. Chaque fois qu'une quantité change, le gestionnaire de l'entrepôt est avisé. Chaque fournisseur surveille le produit qu'il fournit et envoie une commande de réapprovisionnement lorsque la quantité tombe sous un seuil.

java
public class Entrepot implements Sujet {
    private final Map<String, Integer> quantites = new HashMap<>();
    private final List<Observateur> observateurs = new ArrayList<>();
    private String dernierProduitModifie;

    // abonner(), desabonner() et notifier() : identiques à l'exemple de la chaîne

    public void modifierQuantite(String produit, int nouvelleQuantite) {
        this.quantites.put(produit, nouvelleQuantite);
        this.dernierProduitModifie = produit;
        this.notifier();
    }

    public String getDernierProduitModifie() { return this.dernierProduitModifie; }
    public int getQuantite(String produit)   { return this.quantites.get(produit); }
}

public class GestionnaireEntrepot implements Observateur {
    private final Entrepot entrepot;

    public GestionnaireEntrepot(Entrepot entrepot) {
        this.entrepot = entrepot;
    }

    @Override
    public void notifier() {
        String produit = this.entrepot.getDernierProduitModifie();
        System.out.println("[Gestionnaire] " + produit + " : "
            + this.entrepot.getQuantite(produit) + " unités");
    }
}

public class Fournisseur implements Observateur {
    private static final int SEUIL = 10;
    private final String nom;
    private final String produitFourni;
    private final Entrepot entrepot;

    public Fournisseur(String nom, String produitFourni, Entrepot entrepot) {
        this.nom = nom;
        this.produitFourni = produitFourni;
        this.entrepot = entrepot;
    }

    @Override
    public void notifier() {
        String produit = this.entrepot.getDernierProduitModifie();
        if (produit.equals(this.produitFourni)
                && this.entrepot.getQuantite(produit) < SEUIL) {
            System.out.println("[" + this.nom + "] Commande de réapprovisionnement : " + produit);
        }
    }
}
